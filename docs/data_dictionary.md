# REVORA Data Dictionary — Phase 1

This document specifies the dataset schema for **REVORA Payment Intelligence Foundation**.

## Overview & Leakage Prevention Policy

To build robust, leak-free machine learning models in subsequent phases, all dataset columns are strictly categorized into two mutually exclusive groups:
1. **Predictive Features**: Attributes available at or before the initial payment failure timestamp.
2. **Post-Outcome / Target Fields**: Ground-truth target fields generated by the synthetic simulator.

> [!IMPORTANT]
> Post-outcome fields (`recovered`, `recovery_probability_target`) are **strictly prohibited** from being used as inputs to future ML recovery prediction models.

## Prohibited Leakage Fields

The following fields represent future execution outcomes and must **NEVER** be present in training features:
- `final_recovery_timestamp`
- `post_recovery_transaction_status`
- `actual_recovery_action_result`
- `recovered_amount`
- `future_retry_outcome`
